# DAASK Automation Lab

Daily automations built, documented, and shipped as part of the 90-day build challenge. Each folder is one working build with its exported n8n workflow (where available) and a write-up.

| # | Automation | Sector | Technique | Status |
|---|---|---|---|---|
| 001 | Lead capture and follow-up | General | Sheets trigger, conditional routing, scheduled digest | Complete, live |
| 002 | Overdue invoice reminder | SME | Scheduled check, Switch routing on reminder/escalation | In progress |
| 003 | Job application tracker + auto-fill | Personal | RSS ingestion, LLM tailoring, Automa + Playwright/CDP bridge for file upload | In progress |
| 004 | Lexi, Telegram AI assistant | General | LangChain agent, Qwen via DashScope, voice transcription, Baserow/Calendar/Gmail tools | Built, pending Qwen credential setup |

Status reflects what's actually confirmed working, not just what's been designed. Folders get updated as each build clears testing.
